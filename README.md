# Ledger — releases

**[Download the latest Ledger for Windows](https://github.com/cavinindustriesllc/ledger-releases/releases/latest)**

Ledger is a private bookkeeping app for household and small-business money by Cavin Industries LLC:
budgets, bank statement imports, check registers, reconciliation, month close, reports for your
accountant, and an owner's desk for setting aside profit and taxes. Your books stay on your computer.

This repository holds installers and the update feed only. Installed copies of Ledger check here for
new versions and ask before installing; every update is signed with Cavin Industries' release key and
is refused otherwise.

- [Privacy policy](https://cavinindustriesllc.github.io/ledger-releases/privacy.html)
- [Support](https://cavinindustriesllc.github.io/ledger-releases/support.html)

Windows may show a SmartScreen notice the first time, because the installer isn't yet signed with a
code-signing certificate; choose "More info → Run anyway". Mac builds are unsigned: see the release
notes for how to open them.
